VHDL pattern matching uses `std_match`, where `'-'` is a don't-care in the pattern while unknown bits in the message remain observable. For example, `std_match(message, "00--")` accepts every complete message beginning with `00`. Test patterns in priority order inside a process and assign a safe default first. Use `is_x(message)` to decide whether the candidate may be published; this separates family decoding from message validity.
