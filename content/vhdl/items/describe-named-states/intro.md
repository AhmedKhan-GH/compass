An enumerated type gives each controller state a meaningful VHDL name: `type state_t is (stopped, moving, cautious);`. A signal of that type cannot accidentally hold an unrelated bit pattern. One combinational process chooses `next_state` and first defaults it to the current state. A clocked process transfers that choice on `rising_edge(clk)`. A `case state is` statement must cover every enumerated value, which makes transition and output rules easy to audit.
