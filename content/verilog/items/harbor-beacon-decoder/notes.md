# Harbor beacon decoder: author intent

Teach the exact wildcard boundary with a candidate decoder and a separate simulation validity diagnostic. All sixteen known words have a family. The important faults involve required X values, ignored X values, and significant Z values. Public instructions explicitly describe casez's expression-side Z wildcard behavior and ordered matching, so the tests contain no hidden matching policy.

The grader enumerates all 256 four-state words for each task. Its independent Python casez model checks masks and ignores Z in the expression, with no X wildcard except at ignored item positions. Task 2 requires every bit to be known, and task 3 gates the candidate with that property. X/Z enter Icarus through LogicArray and are compared as strings. Incorrect examples change casez to casex, use ordinary inequality for knownness, or publish unchecked candidates.

The diagnostic is explicitly simulation-only. Never describe this code as detecting an arbitrary analog level or making a real radio receiver fail-safe. Waveforms are the authoritative visualization; synthesized known-value circuit views cannot explain four-state acceptance checks.
