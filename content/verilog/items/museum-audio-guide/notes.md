# Museum audio guide: author intent

Teach three distinct declaration failures through one working receiver: a misspelled port connection creates an unrelated implicit net; an undeclared bus becomes one bit; parallel continuous drivers conflict. The module is supplied as a read-only editor file. The starter deliberately compiles so each task can report separately. Stage 1 fixes only the name; stage 2 fixes the width and enables strict declarations; stage 3 repairs the request's driver.

Tests vary every stop and volume, cover all request inputs, and observe actual X/Z on faulty implementations without coercing them to integers. The reference explicitly instantiates the receiver. The grader assesses observable behavior rather than imposing a textual spelling recipe, so an equivalent correct implementation remains accepted. `default_nettype none` is a recommended compiler guard demonstrated by the reference; behavioral tests cannot prove that a learner retained this guard.

Incorrect examples isolate volume truncation and conflicting request drivers. The usable waveform exposes the received beacon, decoded outputs, and request.
