# Trail counter kit

Use a workshop commissioning scenario to compose existing counting/comparison skills while learning real source organization. Four editable files have distinct responsibilities. A guarded macro sets an overridable project default; instance parameters keep individual modules reusable.

Task 1 preprocesses a doubly included header with default and explicit widths. Tasks 2 and 3 independently compile submitted supporting modules with multiple instance parameters, so each can pass before top-level assembly. Task 4 exercises the live default kit in cocotb, then compiles an alternative project default and threshold. Parameter probes operate on the exact submitted `/solution` files. They require successful compilation and an explicit checked verdict; source-text pattern matching is not used.

The real source list contains module `.v` files, with `trail_defs.vh` available on the include path. Never compile the header as a separate module. Private solution-file mappings and JSON bundles preserve all editable files for references, stages, and incorrect examples. Stages finish header, counter, indicator, then top wiring; all later tasks fail until reached.

The early functional tasks use independent tiny simulator probes. The saved default waveform is useful once the assembled top works; the live Circuit view renders the learner's assembled top and supporting modules, not the probe harnesses.
